# Atelier verification evidence

This package preserves three complete raw runs and selects exactly 420 successful
study renders in studies.json. Street and perspective come entirely from the
recovery run. Only Naturalist Plate and Surface Pointillism are replaced by the
anchor supplement on tabletop, room and topology. Each selected render records
its evidenceRun. No earlier report is substituted for missing final evidence.

The initial run retains 15 street worker failures. The accompanying observed
service-restart log documents concurrent restarts; the original failures are not
rewritten as passes. Source regression is 15/16: contact-worker rejects adapted
function/descriptor hashes under its historical source-identity gate.

Images are deliberately labeled base, recovered, or anchor supplement; no contact
sheet is silently edited to resemble a single final run. The three base contact
sheets predate the anchor repair. Inspect their separately named two-study panels.

verification.json inventories every payload file (excluding itself) with SHA-256. installed-file-
hashes.json is the guarded installation snapshot checked when this package was
created; later narrative documentation edits do not retroactively change that
snapshot. checks.json records actual unit/build counts, the installed style/request/layer
UI checks, six-roll Atelier conformance, material repeats, and source-regression results. The final installed unit/build logs are authoritative;
the staging aggregate is earlier evidence predating the final custom-shader profile repair. catalogue/verification.json confirms the same 1,986
unique component IDs passed before and after the port. Only two complete clean
final shards contribute to that count. The first shard attempt, its historical
circus-scene TypeError reading 'copy', and the clean isolated/preceding-sequence
diagnostics are retained under catalogue/. Isolated and preceding-sequence diagnostics
did not reproduce that error. The separate optimizer-collision proof reproduces the
same mechanism with duplicate Three module generations and overlapping numeric light
IDs; attribution to the historical incident remains inferred because its optimizer
hash and browser module URLs were not preserved. No speculative code fix is claimed.

capture/ preserves the final actual GPU custom-shader proof, its source script,
and all-22-factory/native-PBR profile parity proof. The parity baseline explicitly
reconstructs the old function by removing only the three validated ordinal additions.
The GPU proof also audits all five study fixtures for native-only material profiles,
which connects the prior study renders to the unchanged paths after the custom-only fix.
The initial audit report is retained separately: its custom GPU cases passed, but
instrumentation imported a second Vite CaptureRig class and observed zero fixture
captures. Only the completed final proof, using the actual loaded module identity,
counts toward verification.
